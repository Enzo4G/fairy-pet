## 2026-11-06 · 贴边隐藏 / 掉不出屏幕 / 权限可切

一句话：贴边能藏起来了，改分辨率不会再把它甩丢，dsh 版的权限也能在小窗里直接切。

### 新功能

**贴边隐藏**（右键菜单勾选，默认关）

拖到屏幕任意一条边松手，身体就滑出去，只留本体 1/10——露出来的是眼球边缘那一角，不是透明光环的留白。鼠标停上去探出 1/3，按住可以直接把它拖出来；只有原地松手（没拖动过）才带平移动画滑回原位。判定贴不贴边看的是**鼠标**离边缘多远，不是宠物离边缘多远，所以大字号、拖过头都照样生效。

**不会被甩出屏幕**

每 1.5 秒自检一次位置。改分辨率、拔掉副屏、把宠物拖到屏幕外，只要不到 1/3 还落在可视区，就会被拉回来。启动时也会先校正上次存的位置。

**权限可在小窗里切**（dsh 版）

「权限」按钮现在是完整菜单：仅可查看 / 工作区内修改 / 完全权限，当前项打勾。走的是客户端同一入口（在会话里执行 `/permission <preset>`），改完标签立刻跟上。

「模式」（标准 / PTC / 精简 / Cordis）只能在对话第一条消息之前选——这是 dsh 的规则，已经开始的会话它自己也会拒绝。以前点了没反应，现在会在提示行写原因。

### 变化

**Hana 版去掉「新建对话」**

Hana 的会话列表由客户端维护，外部进程建出来的会话不会实时出现在侧栏，点一次就留一个看不见的空会话。要开新对话请在 Hana 里点，桌宠的下拉里选中它即可。

### 修复

- **认错端口**：以前按"首页里有没有 dsh 字样"挑端口，本机另一个服务刚好也写着 dsh，于是连过去、整窗报「dsh 拒绝授权」。现在先发一次 `session/list`，验证通过才认。
- **贴边后悬停没反应**：拖到边缘松手时指针本来就压在窗口里，`enterEvent` 永不来，改成 150ms 轮询指针位置。
- **弹回后重启又跑出去**：原来存的是拖动前那个越界坐标，现在存弹回后的落点。
- **「没后端就自杀」**：从未连上过时只空转等待，连过再断才退出——开机自启时桌宠可能比客户端先起来。
